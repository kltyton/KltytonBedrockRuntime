The lexer, parser and runtime are rebuilt for Java 17 from pinned source artifacts.
The original MIT notices are retained; the upstream source packages are relocated
into KBR's isolated internal package for the derived build.
KBR patches add resource-version parsing rules, numeric operators and an opt-in
contextual evaluation path for particle bindings and structured control flow.
The bytecode compiler is not included. Minecraft supplies Netty at runtime.
